## Notes on precision (disclosed discrepancies, not defects)

- **Appid ≠ directory name** for 4 apps: `programmer_calc`→`programmercalc`,
  `boilerplate`→`fap_boilerplate`, `minesweeper`→`minesweeper_redux`,
  `barcode_gen`→`barcode_app`. All confirmed intentional upstream naming,
  not import errors.
- **Two apps ship with no formal LICENSE file**: `network_subnet` and
  `flipper95` — attribution exists only via `fap_author`/`fap_weburl`
  and README; no license type is asserted for either. This is a
  disclosed evidence gap, not a claim of unlicensed/prohibited use — see
  `docs/THIRD_PARTY_LICENSE_AUDIT.md` for the full license-tier
  breakdown.
- **`sd_info` is the one app in the entire project whose write target is
  not app-private** (SD-card root `/ext/sdtest.tmp*` rather than
  `/ext/apps_data/sd_info/`) — reviewed and accepted as safe because the
  writes are transient, user-initiated, and self-cleaning, not because
  the location itself is app-scoped. See
  `docs/STORAGE_AND_DATA_BEHAVIOR_AUDIT.md`.
- **`docviewlite` and `network_subnet` both declare `fap_icon_assets`
  pointing at directories that don't hold real icon assets** —
  pre-existing upstream discrepancies, confirmed harmless (CI builds
  succeed for both), not introduced by any import step in this project.
