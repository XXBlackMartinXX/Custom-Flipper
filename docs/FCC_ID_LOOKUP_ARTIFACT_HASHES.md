## What this does and does not mean

- **These are real hashes of the actual downloaded files**, computed with
  PowerShell's `Get-FileHash -Algorithm SHA256` on a GitHub-hosted Windows
  runner that downloaded them directly from the source CI run via
  `gh run download`.
- **No binary is committed to this repository.** `firmware.dfu`, the
  updater `.tgz`, and every `.fap` file exist only as GitHub Actions
  workflow artifacts on the source run; only their hashes (text) are
  committed here.
- **No FCC frequency/applicant database file is bundled, generated, or
  hashed by this workflow** - fcc_id_lookup never bundles that database;
  this remains unchanged by finalization.
- **Hardware-assisted validation: NOT RUN. Hardware flashing/testing: NOT
  PERFORMED.**
- **Release status: TEST-READY ONLY / NOT RELEASE-READY.** Generating these
  hashes does not change either of those.
