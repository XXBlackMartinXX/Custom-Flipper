## Firmware/updater SHA-256

**PENDING.** Real, independently-computed SHA-256 hashes of the actual
`firmware.dfu` and updater `.tgz` files (not the zip-archive digests
above) require downloading and extracting the artifact — this session's
own network path cannot do that directly (GitHub Actions artifact
downloads always redirect to Azure Blob Storage, which this session's
egress policy blocks with a confirmed `403`, the same limitation
documented since Phase 2A.10). `.github/workflows/phase2b-finalize-baseline.yml`
resolves this the same way Phase 2A.11 did: running entirely on GitHub's
own Windows infrastructure, downloading the artifacts directly via
`gh run download`, and hashing them with `Get-FileHash`. See
`docs/PHASE2B_3_ARTIFACT_HASHES.md` for the real values once that
workflow has run.

## Where these artifacts live

**These artifacts are stored only as GitHub Actions workflow artifacts
tied to run `28877810474` — they are not, and will not be, committed as
binaries to this repository**, consistent with this project's standing
policy against committing `build/`, `dist/`, or `toolchain/` output.
GitHub retains workflow artifacts for a limited window (90 days, per the
workflow's own `retention-days: 90` setting; the API reports an explicit
expiry of 2026-10-05 for both artifacts above) — after that, they are
deleted by GitHub regardless of anything in this repository.

## Validating a real device flash later

Once a physical Flipper Zero and Windows machine are available,
`tools/phase2a_hardware_gate.ps1 -Mode HashVerify -ArtifactDir <path>`
can verify a locally-downloaded copy of these two files against the real
hashes in `docs/PHASE2B_3_ARTIFACT_HASHES.md` before any flash is
considered — the same discipline already used for the Phase 2A-only
baseline in Phase 2A.12 (that gate's config would need a Phase
2B-pointing copy or a `-ConfigPath`-style extension to reference the
Phase 2B hash values specifically; not created in this phase, since no
device or Windows machine is available to use it against here).
