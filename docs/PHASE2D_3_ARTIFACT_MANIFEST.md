**PENDING.** Real, independently-computed SHA-256 hashes of the actual

above) require downloading and extracting the artifact — this session's

on GitHub's own Windows infrastructure, downloading the artifacts
directly via `gh run download`, and hashing them with `Get-FileHash`. See
`docs/PHASE2D_3_ARTIFACT_HASHES.md` for the real values once that
workflow has run.

## Where these artifacts live

**These artifacts are stored only as GitHub Actions workflow artifacts
tied to run `28941093859` — they are not, and will not be, committed as
binaries to this repository**, consistent with this project's standing
policy against committing `build/`, `dist/`, or `toolchain/` output.
GitHub retains workflow artifacts for a limited window (90 days, per the
workflow's own `retention-days: 90` setting; the API reports an explicit
expiry of 2026-10-06 for all three artifacts above) — after that, they
are deleted by GitHub regardless of anything in this repository.

## Validating a real device flash later

Once a physical Flipper Zero and Windows machine are available, a
Phase-2D-pointing hardware gate (modeled on
`tools/phase2c_hardware_gate.ps1`/`tools/phase2c_hardware_gate_config.json`,
not created in this phase since no device or Windows machine is available
to use it against here) could verify a locally-downloaded copy of these
two files against the real hashes in `docs/PHASE2D_3_ARTIFACT_HASHES.md`
before any flash is considered — the same discipline already used for the
Phase 2A/2B/2C baselines.
